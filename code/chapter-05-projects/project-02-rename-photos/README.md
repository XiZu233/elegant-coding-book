# 项目二：批量重命名照片

## 项目描述

从相机或手机导出的照片，文件名通常是一串无意义的数字，比如 `IMG_20240115_143022.jpg`、`DSC_0001.jpg`。

这个脚本会把它们改成有意义的格式：按**文件修改日期**分组，每组按顺序编号，重命名为 `YYYY-MM-DD-001.jpg` 这样的格式。

## 文件说明

| 文件 | 说明 |
|------|------|
| `rename_photos.py` | 主脚本，包含完整的重命名逻辑 |

## 如何运行

### 1. 在照片文件夹中运行

把 `rename_photos.py` 复制到要处理的照片文件夹中，然后运行：

```bash
python rename_photos.py
```

### 2. 指定文件夹路径

修改脚本最后一行的 `folder = Path.cwd()` 为指定路径：

```python
folder = Path(r"C:\Users\你的用户名\Pictures\相机照片")
```

### 3. 作为模块导入使用

```python
from rename_photos import rename_photos
from pathlib import Path

# 重命名指定文件夹的照片
rename_photos("/path/to/photos")

# 添加前缀
rename_photos("/path/to/photos", prefix="旅行")
# 结果：旅行-2024-01-15-001.jpg
```

## 运行流程

1. 脚本扫描文件夹中的图片文件（.jpg, .jpeg, .png, .bmp, .webp）
2. 按**文件修改日期**（不是文件名里的日期）分组
3. 显示**预览列表**：显示原文件名和新文件名
4. 询问是否添加前缀（如输入"旅行"，则变成 `旅行-2024-01-15-001.jpg`）
5. 询问确认：输入 `y` 执行，输入 `n` 取消
6. 确认后执行重命名

## 安全机制

- **先预览、再执行**：重命名前会显示完整预览并询问确认
- **重名处理**：如果目标文件名已存在，自动加序号避免覆盖
- **只处理图片文件**：不会误操作其他类型文件
- **文件夹不存在检测**：如果指定的文件夹不存在，会提示错误并退出
