# 项目一：自动整理下载文件夹

## 项目描述

你的"下载"文件夹是不是这样的：图片、PDF、压缩包、安装程序全混在一起，找文件得翻半天？

这个脚本会自动扫描下载文件夹，按文件类型分类到子文件夹：

- **图片**（.jpg, .png, .gif 等）-> 移到 "图片" 文件夹
- **文档**（.pdf, .docx, .txt 等）-> 移到 "文档" 文件夹
- **压缩包**（.zip, .rar, .7z 等）-> 移到 "压缩包" 文件夹
- **其他文件** -> 移到 "其他" 文件夹

## 文件说明

| 文件 | 说明 |
|------|------|
| `organize_downloads.py` | 主脚本，包含完整的整理逻辑 |

## 如何运行

### 1. 直接运行（整理默认下载文件夹）

```bash
python organize_downloads.py
```

默认会整理当前用户的下载文件夹（Windows 通常是 `C:\Users\用户名\Downloads`）。

### 2. 作为模块导入使用

```python
from organize_downloads import organize_downloads
from pathlib import Path

# 整理指定文件夹
organize_downloads("/path/to/your/folder")

# 只预览，不真正移动文件
organize_downloads("/path/to/your/folder", dry_run=True)
```

## 运行流程

1. 脚本扫描目标文件夹中的所有文件
2. 显示**预览列表**：告诉你哪些文件会被移动到哪里
3. 询问确认：输入 `y` 执行，输入 `n` 取消
4. 确认后执行移动操作

## 安全机制

- **只移动文件，不移动文件夹本身**
- **先预览、再执行**：移动前会显示完整预览并询问确认
- **重名处理**：如果目标位置已有同名文件，自动在文件名后加数字避免覆盖
- **文件夹不存在检测**：如果指定的文件夹不存在，会提示错误并退出
