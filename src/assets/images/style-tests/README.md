## 风格分组建议

### 按教材章节匹配

| 章节类型 | 推荐风格 | 理由 |
|----------|---------|------|
| 开篇/封面 | 05 高级黑金、01 温馨可爱 | 第一眼印象，需要冲击力或亲和力 |
| 概念解释（04/06章） | 02 现代简约、06 扁平插画 | 信息清晰，不分散注意力 |
| 工具教程（03章） | 03 科技未来、02 现代简约 | 与科技主题契合 |
| 实战案例（05章） | 06 扁平插画、08 手绘涂鸦 | 步骤清晰或轻松有趣 |
| 安全/红线（07章） | 02 现代简约、04 专业商务 | 严肃可信，警示感 |
| 印刷版（黑白） | 09 线稿描边 | 唯一无需彩色即可输出的风格 |

### 按统一性优先排序

如果全书只能选 **1 种风格**：

1. **首推：06 扁平插画** — 现代 UI 通用风格，信息传达最清晰，跨平台兼容性好，AI 生图成功率最高。
2. **次推：02 现代简约** — 专业感强，适合技术类教材，但可能略显冷淡。
3. **备选：08 手绘涂鸦** — 亲和力强，与「零基础小白」定位契合，但批量生成一致性较难控制。

## 下一步操作建议

1. **生成对比**：将 `prompts.md` 中的 9 个 prompt 复制到 Nano Banana（即梦）或 Midjourney 生成。
2. **并排对比**：将 9 张图放在同一屏幕下观察，关注：
   - 大礼堂主体是否清晰可辨
   - 风格是否适合技术教材的调性
   - 同一风格下批量生成的一致性
3. **选定风格**：确定 1 种主风格 + 1 种备用风格。
4. **批量生成**：用选定风格替换 `scripts/generate_images.py` 中的 prompt 模板，批量产出 34 张教材配图。
